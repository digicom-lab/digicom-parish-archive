# DigiCom Digital Parish Archive Microsite

This microsite presents the proposal for the **Digital Parish Archive Initiative**, a project aimed at helping Catholic parishes preserve sacramental records through digital archiving.

## Purpose

The initiative supports:

- Preservation of sacramental records
- Faster parish certificate processing
- Protection of historical parish archives
- Improved service for overseas Filipino families

## Structure

The microsite includes:

- Challenge overview
- Proposed solution
- Benefits for parishes and communities
- Pilot program proposal

## Deployment

This project can be deployed using **GitHub Pages**.

Steps:

1. Upload repository to GitHub
2. Go to repository settings
3. Enable **GitHub Pages**
4. Select `main` branch
5. Site will be published automatically
